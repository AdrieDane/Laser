Decision:
Keep this whole algorithm as a research reference because correct counts improve
in all four pooled modes, the capped class-average improves, and the overall
gain is useful. Accept explicitly the 103-extra / 39-wrong-feature cost for 280
additional correct matches. This fails a strict no-increase rule against 027.
It still has 351 fewer extras than the ORIGINAL 9697-extra baseline.
This is not proof of analytical false discovery rate, and not ready for an
automatic production upgrade. Do not splice successful old class/mode outputs.
