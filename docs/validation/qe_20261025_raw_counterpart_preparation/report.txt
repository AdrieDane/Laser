WHY THIS IS DIFFERENT
Previous paired-profile evidence depended on a strong BASELINE AUTOMATIC
annotation in the other mode. The new, unused prototype searches original
OTHER-POLARITY raw peaks using the candidate's native class/phase adduct and
charge. An unassigned partner can therefore supply numerical evidence. This
does not create a new candidate or accept the partner as an annotation.
Native review-only ions remain evidence-only. RP and NP are never RT-linked.

RT AVAILABILITY — COMPLETE, NO MANUAL FILES USED BY THE RT AUDIT
Existing independently detected shared standards supply at most1 RP pair and
2 NP pairs per dataset. They cannot justify a general RT map. Additional
declared-spike native ion searches were therefore tested with strict mass,
uniqueness, independent-compound/FID and RT-fit checks.

RP:8/33 datasets qualify for a global within-phase polarity RT relation.
NP:18/33 qualify for an EXACT Cer[d] class relation only. This is NOT a global
NP relation and supplies no NP PE/PC RT support. Each direction uses the SAME
observed pairs, not independent new observations. Unsupported mappings stay
unknown; those datasets are not discarded as generally unusable.

RP checks:>=6 distinct spike compounds,>=120s span, bounded affine relation,
leave-one-standard-out median error<=2s and90th percentile<=4s, limited source-
RT interpolation range. NP checks:>=2 distinct spikes in the exact class,
offset MAD<=2s. Raw alternate-ion searches require<1.5ppm and unique hits in
a coarse30s search seeded by an already trusted shared spike. No seed means
no augmentation. Disagreeing/ambiguous aliases are withheld, not accumulated.

PROFILE MEASUREMENTS — UNDER NUMERICAL VALIDATION
The second prototype produces32 numeric fields. Opposite-polarity raw peaks
must be within3ppm of native predicted masses. It uses explicitly validated
MS_metadata specimen links only;30 datasets have supported pairing,3 do not.
Technical-replicate areas are averaged before taking logarithms. Biological
correlations require>=8 paired specimens, within-group correlations also>=4
residual degrees of freedom. QC/blanks never supply biological correlation.
Normalization uses raw global sample medians, not curated target annotations.

Measurements include raw/normalized/within-group correlations, Spearman,
leave-one-specimen-out robustness, log-ratio location/MAD, distinct-partner
counts and ambiguity. Raw RT differences are NOT confirmed RT residuals.
RT-supported measurements require a qualifying independent spike relation.
