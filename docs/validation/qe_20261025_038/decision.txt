Decision: reject experiment 038. Keep 029 as the retained research version.
The application defaults have not changed.

All 33 active datasets and four modes were benchmarked. The complete 132-row
before/after table and separate wrong-peak totals were delivered in the user

The first audit checked all 25 models and 132 inner validation cases, but
stopped when a nullable previous-peak ID was read from CSV as a number

raw CSV text preserved; numeric measurements keep their original strict

All 33 outer output/measurement checks were rerun successfully. The 25 model

The final 63-case receipt passed: 310 source and 1,132 input file checks,

What was tested
The method learned which original peak to choose for an already accepted
lipid. It could not add or remove lipid identities, change standards, borrow
an occupied peak or chain several replacements. It retained the original
mass/RT limits and spike protections. A replacement copied the actual new
feature's sample values and peak boundaries.

There were 25 fresh model fits, containing 100 mode-specific classifiers,
with 180 training rounds each. Move thresholds were chosen using inner
training-group validation. Relevant query, outer-test and inner-validation
groups were excluded from learned references and classifier fits. The query
dataset's manual annotations were not used for prediction.

Why it was rejected
There was no overall gain. PI, already below 90%, got worse; CL was already
above 90%. The class-by-class target did not improve. Do not keep only the
favourable NP-negative result or relax 038's rules after seeing these tests.
The whole method is rejected.
