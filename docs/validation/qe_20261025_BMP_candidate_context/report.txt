Strong opposite-polarity evidence in many unconfirmed options is consistent
with the known manual convention of listing BMP in only one NP polarity.
It does NOT prove those calls chemically correct. Opposite manual support is
used ONLY as a descriptive evaluation category; it is never a runtime filter
or predictor. ALL such calls remain unconfirmed extras in primary evaluation.
Correlation can reflect shared sample effects, not chemical identity.

Conclusion: worth a proper nested annotation experiment, unlike the small
general peak/label swapping opportunities. It is not itself a deployment rule.
Future fitted use needs363 separately scoped candidate graphs, not unioned
membership across reference masks. Physical-only raw-profile memoization may
be shared but cannot create target candidates from an excluded reference.
Any revised extras tradeoff must be prospectively explicit, total extras still
reported, and cannot be retrofitted after seeing the new annotation results.
