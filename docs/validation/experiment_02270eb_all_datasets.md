# All dataset and mode results for the RP positive consensus experiment

21 October 2026. Before is `a06782f`; after is `02270eb`. The experimental PE
option is enabled in both. This is the last completed annotation-changing
experiment, not a comparison against the option-off default. No new annotation
experiment is run to produce this expanded report.

Correct means the same lipid, adduct and ORIGINAL peak as the curator selected.
Extras are annotations absent from that dataset and measurement mode's manual
list, not proven incorrect lipids. Before and after values appear on each row,
including unchanged modes. Bold match counts identify the three changed rows.
The duplicate fish folder is shown but excluded from every total.

## All lipid classes

These counts include all lipid classes, not just PE. Overall correct matches
change from 34,348 to 34,351. Extras stay at 3,652 and different-peak calls stay
at 534. Total calls change from 38,887 to 38,890. A further 353 calls have a
manual identity whose original peak mapping is unresolved; those are not
classified as correct, different-peak or extra.

## Denominators and verification

The all-class [full numerical table](experiment_02270eb_all_classes.csv) includes
manual row counts, reliably mapped denominators, percentages, different-peak
choices, total calls and manual entries not on the same peak. The latter
includes unresolved mappings and different-peak choices; it is not a count of
identities entirely absent from LASER. All-class percentages use unique,
reliably mapped manual entries; PE percentages above use all manual rows.
These denominators are intentionally different and must not be conflated.
The [existing PE numerical table](rp_pe_consensus_by_dataset_20261021.csv)
contains all 60 PE dataset/mode rows.

All 15 retained core outputs were replayed through the final selector, with
fresh full-input controls for V2 and cells, including an additional final-source
cells control. This is not 15 new full-input runs. Fish and Serhii source folders
are currently absent; their rows use saved original-feature tables and earlier
full outputs. All examples informed development, not external validation.
See the [experiment report](rp_pe_consensus_20261021.md) and
[provenance manifest](rp_pe_consensus_provenance_20261021.json) for checks,
limitations and the rejected alternatives. No previous TXT export is regenerated.
